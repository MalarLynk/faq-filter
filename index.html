Category Question Answer
Codiac
Codiac When will these schemes finally be integrated into Codiac? This way of scheduling is outdated and does not work pleasantly. They won't be more integrated. The wiring diagram is what we are using, and we will not build it like VIDA. The system does not work that way. We will never have guided diagnostics. Start by checking TJ under Operation in Codiac and CSC in Work Order App.
Codiac So then no plug may be replaced? Does the entire wiring harness have to be replaced? No plug can be replaced unless there is a specific operation for it. Example: pressure sensor particle filter connector. This is only for that specific use case.
Codiac Air Conditioning Service - Will workshops be able to order Washers or PAG Oil? No chemical supplies are provided. We provide specifications. Exception: transmission oil for 01MY25 and 08.
Codiac Will we be able to order spare parts without entering VIN? No.
PDS
PDS When will we see order history on downloaded software? No, this will not be available.
PDS Is it possible to lock the car in transport mode and unlock without PDS? No, you may not lock.
DTC
DTC Will we be able to see old readouts of error codes after deletion? Yes, this will be launched.
DTC When will we see older DTCs if the car was recently read out? It is under development. The first draft looks promising and is expected in the future.
Work Order App
Work Order App When operations and parts are added, approval causes repair delays and duplicate orders. In Work Order App in Codiac, when adding an operation you can select and remove unnecessary parts before ordering.
Warranty
Warranty Why is there no longer standard troubleshooting linked to warranty application based on CSC? Troubleshooting must now be booked manually.
Warranty How long does warranty pre-approval take? Within one working day (Monday-Friday). Pre-approval requests are recommended.
High Voltage
High Voltage Can we charge HV battery without using Codiac? No. The function is disabled for safety reasons.
High Voltage Will it be possible to print the high-voltage battery health test? No, this is currently unavailable. Sellers should submit a feature request to Lynk & Co Retail Support.
